# 成都日最高气温：三个模型谁更准

两个文件，跑一个就出结果。回答的问题是：
**只给前几天的气温，能不能预测明天的最高温？比"明天和今天一样"准多少？**

## 两个文件

| 文件 | 干什么 |
|---|---|
| `run.py` | 抓数据 → 造特征 → 训三个模型 → 评估 → 出图。全部在这一个文件里 |
| `app.py` | 网页版，能按日期查某一天三个模型各预测多少度 |

## 怎么跑

在文件夹里按住 `Shift` + 右键 →「在终端中打开」，然后：

```bash
python run.py              # 抓新数据（没网会自动用合成数据）
python run.py --no-fetch   # 用已有的 data/chengdu.csv，快
python run.py --synthetic  # 强制合成数据，只为验证流程

streamlit run app.py       # 网页版（可选）
```

输出：`outputs/metrics.json`（所有数字）、`outputs/chart.png`（图）。

## 任务和数据

- 地点：成都（30.57°N，104.07°E）
- 数据：Open-Meteo 历史日值，2016-01-01 起，逐日最高温/最低温/降水
- 切分：前 80% 训练、后 20% 测试，**按时间切，不打乱**
- 输入：前 1/2/3/7 天最高温、前一天最低温、年周期 sin/cos
- 输出：当天最高温

## 三个模型

| 模型 | 做法 | 为什么要有 |
|---|---|---|
| 持久性 | 明天 = 今天 | 气象界的经典基线 |
| 气候平均 | 历年同期 ±3 天均值 | 代表"只看季节、不看过程" |
| 岭回归 | numpy 写的闭式解，λ=1 | 待检验的模型 |

## 真实结果（成都，3960 天）

| 模型 | MAE | RMSE | 比持久性 |
|---|---|---|---|
| 持久性 | 1.99℃ | 2.60 | — |
| 气候平均 | 2.88℃ | 3.73 | 差 45% |
| **岭回归** | **1.93℃** | **2.43** | **好 3%** |

分季节（岭回归 / 持久性）：春 2.44 / 2.59、夏 2.07 / 2.07、秋 1.53 / 1.59、冬 1.81 / 1.87。

**春天最难预报**：气候平均在春季误差 3.51℃，说明"历年同期均值"完全抓不住春季的冷暖反复。

## 结论（写在报告里的那版）

> 只用气温外推，误差就在 2℃ 上下，比"明天等于今天"只好 3%。要再往上，得加更多要素（环流、水汽、多站），而不是把模型换复杂。

## 局限（主动说）

- 单站、单要素，没有环流场；
- 线性模型，对冷空气过境这种突变无能为力；
- 没用业务数值预报产品做对比。

## 答辩两个必答问题

1. **为什么用 MAE 不用"准确率"？** 气温是连续值，没有对错，只有差几度；准确率要先划一个"±1℃ 算对"的阈值，会掩盖问题。
2. **为什么气候平均最差？** 它没有天气过程的信息，成都春秋起伏大，均值反而误导。
